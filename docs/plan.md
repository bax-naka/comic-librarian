# 計画（2026-11-23 作成）

旧「Comic Library Organizer」（ChatGPT＋Codex/OpenHands、Android/SAF/Kotlin）を前提にせず、一から組み直した計画。
旧成果は bundle として保全済み（参照専用）。

## 方針

- 個人用。必要十分な品質に留め、段階ごとに実際に使って確かめてから次へ進む
- 作る前に既存ツール・OSSを調べる（照合は Kavita のパーサ等を参照、移動は rsync、RAR は libarchive の予定）
- 処理の中核（照合・計画・移動）は Python 1本にまとめ、画面を付けても使い回す

## 段階

| 段階 | 内容 | 次に進む条件 | 状態 |
|---|---|---|---|
| 1 | コンソール版：手順4 Titan 1 → 4.5 Galaxy Tab S11 事前確認 → 5 本番で1回 | 本番で1回問題なく使えた | 手順1〜3 完了 |
| 2 | 表紙の取り出し確認（ZIP=zipfile、RAR=bsdtar） | 全書庫で取得でき、実用的な速さ | |
| 3 | ブラウザ画面（Termux上の小さなWebサーバー）：全件を表紙付きで一覧、要確認の選択、実行 | コンソール版より毎回の作業が楽 | |
| 4 | ライブラリの状態把握（下記） | 必要な情報が見られる | |
| 5 | 専用アプリ化の判断 | 段階3で不足があれば | |

### 段階4で見たいもの（利用者の要望）

- 作品一覧、検索
- 保持巻数と、どの巻に s・w などが付いているか
- 表記揺れの修正（変更は移動と同じ安全基準で）
- ライブラリ直下と特別フォルダ（`_` 始まり）ごとの作品数・巻数・容量
- `_single` のファイルがライブラリの作品と重複していないかの確認と、その後の移動・削除

## 確認済みの事実

- Titan 1（Android 16、Termux Google Play版）：SDカードへ通常のパスで読み書き可。SD内の移動は付け替え（300MB で 0.06秒）、本体→SDは rsync で約60MB/秒。同名があれば上書きせず元も残る。中断しても書きかけは残らない
- 新刊のダウンロードフォルダは本体内部ストレージ、ライブラリはSDカード（本番は Galaxy Tab S11）

## 決定事項

- 新規作品はライブラリ直下に作る（分類は後で手で行う）
- 移動不要は新刊フォルダに残す（利用者が確認して削除）
- 元ファイルは移動成功後すぐ削除してよい（ログが残り、再取得可能）

## 未確定・注意

- 判定のしきい値は暫定（Titan のサンプルを見ながら決めたので独立した評価ではない）。本番ライブラリの一覧で調整する
- 題名が似ているだけの別作品（例：異世界居酒屋「のぶ」と「げん」）は要確認に回る。本番で件数を確認する
- `data/titan_samples.tsv` は端末出力の貼り付けから作ったため、折り返しで入った余分な空白が一部のパスにある
